# Vellum PDF Studio

A browser-based PDF editing workspace with a real local PDF rendering/export pipeline.

## Included workflows

- Real PDF.js rendering for uploaded PDFs, multi-page navigation with live thumbnails, zoom, fit, rotate, and fullscreen controls.
- Editing tools for selection, text blocks, drawing, highlighting, comments, redaction marks, and fillable form fields.
- PDF-lib export that burns text, highlight, redaction, and comment marks into a downloadable edited PDF.
- OCR, trusted signing, sharing/review, accessibility status, AI summary, and document structure entry points.
- Configurable page inspector for page size, orientation, bleed guides, colors, opacity, and advanced document intelligence.

OCR, signing, sharing, accessibility, and document-intelligence panels are explicit workflow entry points; OCR/signing backends require a service integration, while local rendering and annotation export work offline.
